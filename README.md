Proyecto: Análisis de Ventas de la Industria Automotriz

Descripción del Proyecto

Este proyecto presenta un análisis descriptivo de las ventas del sector automotriz correspondientes al año 2024, esta desarrollado desde una base de datos por periodo temporal, marca, país, canal de venta y tipo de vehículo. El resultado del análisis se resume en un dashboard interactivo que permite ver el comportamiento de las ventas en términos de unidades vendidas e ingresos generados.
El dashboard está hecho para facilitar la comprensión de la evolución del mercado desde diferentes filtros y permite identificar patrones relevantes y comparaciones clave que apoyan la interpretación del desempeño del sector durante el año analizado.

Objetivo del Análisis

El objetivo principal es, comprender el comportamiento de las ventas del sector automotriz en 2024, identificando tendencias temporales, marcas líderes y la distribución de las ventas por canal y tipo de vehículo. A través del dashboard, se busca proporcionar una herramienta visual que apoye la toma de decisiones y el análisis estratégico del mercado.

Estructura del Proyecto

El proyecto se organiza en torno a un conjunto de datos base, una transformación y limpieza de datos y una hoja de análisis de los datos y el dashboard final, que concentra los resultados del análisis. 

Instalación y Requisitos

Para reproducir o explorar este proyecto es necesario contar con: 
•	Microsoft Excel 
•	Sistema operativo Windows.

Resultados y Conclusiones

El análisis muestra que durante 2024 el sector automotriz alcanzó un volumen total de 21.513 unidades vendidas y lo que generón ventas totales de 796.510 €. La evolución mensual evidencia variaciones a lo largo del año, con picos de ventas en enero marzo y mayo sin embargo mantiene una tendencia relativamente estable.
Renault se posiciona como la marca con mayor volumen de ventas, mientras que VMW se posiciona como la marca de mayor número de unidades vendidas. En cuanto a los canales de venta, se observa una distribución equilibrada entre concesionario, flotas y ventas online, lo que refleja la diversificación de los puntos de contacto con el cliente.

Conclusiones

El dashboard nos permite tener una visión general y clara de ventas en el sector automotriz.  Nos permite ver las tendencias y saber en que meses poder realizar refuerzos de comunicación o comerciales desde los puntos de mayor contacto con los clientes. Tener una clara visibilidad de la competencia y sus países y modelos potenciales, facilita la identificación de tendencias y comparativas claves, para el seguimiento del rendimiento y la toma de decisiones estratégicas.
